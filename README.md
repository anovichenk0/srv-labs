# Лабораторные работы

Каждая работа находится в отдельном каталоге и имеет собственный `main.cpp`:

- `labs/1/main.cpp` — обратный обход строки, факториал и сравнение потоков;
- `labs/2/main.cpp` — три потока, синхронизированный и несинхронизированный вывод;
- `labs/3/main.cpp` — делёж монет Бобом и Томом с использованием `mutex`.
- `labs/4/main.cpp` — три толстяка и Кук, три гарантированных исхода;
- `labs/5/main.cpp` — та же модель с собственным `SpinMutex`;
- `labs/6/main.cpp` — корутины C++20 и прогресс-бар с именем.

## Окружение

Сборка и запуск всех лабораторных проверялись в следующем окружении:

- ОС: macOS 27.2.1;
- IDE: CLion 2026.3.0.1;
- процессор: Apple Silicon;
- стандарт языка: C++20.

## Сборка

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Для замеров Debug замените `Release` на `Debug` и используйте отдельный каталог сборки.

## Запуск

```sh
./build/lab1
./build/lab2
./build/lab3
./build/lab4
./build/lab5
./build/lab6
```

В CLion выберите конфигурацию запуска от `lab1` до `lab6`.

## Отчёты

Word-отчёты со снимками реальных запусков находятся в каталоге `reports/`.
